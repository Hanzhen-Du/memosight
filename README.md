# MemoSight

**本地优先、全程离线的可穿戴视觉记忆助手。**  
把摄像头看到的现实信息转成可搜索的 memory card（时间戳 + OCR 文本 + 标签）。

---

## 问题

可穿戴感知设备面临"三难困境"：

| 目标 | 冲突 |
|------|------|
| 常开感知 | 持续推理功耗高 |
| 端侧处理 | 计算资源受限 |
| 长续航 | 电池容量有限 |

同时满足三者，目前没有开箱即用的方案。

## 核心方法：级联守门员感知

```
摄像头帧流
    │
    ▼
[守门员] ── 无趣 ──▶ 丢弃（低功耗待机）
    │
  有趣
    │
    ▼
[高清抓帧 + OCR] ──▶ memory card 写入本地
```

一个廉价的常开分类器（守门员）决定何时值得唤醒昂贵的 OCR 流水线。  
大多数帧在守门员处被过滤，系统整体功耗大幅降低。

## 首发场景

白板 / 文档 / 文字捕捉。

## MVP 目标

- [ ] 训练一个守门员二分类模型（有文字 vs 无文字）
- [ ] 绘制"功耗 vs 漏报"权衡曲线（precision–recall / FPR）
- [ ] 在树莓派原型上完成端到端验证

## 项目结构

```
memosight/
├── gatekeeper/   # 守门员模型：训练、评估、导出
├── pipeline/     # 下游流水线：OCR、memory card 生成、存储
├── data/         # 数据集（不进 git）
├── scripts/      # 功耗测量、评估等工具脚本
└── notebooks/    # 探索性实验
```
