# 探针集误触发测试（probe FP audit）
> 直接量「真实有人、无屏幕文字」场景下守门员的误触发率(FP)。每张探针图按定义都该「不记」，任何「记」都是 FP。**仅诊断，未重训、未改数据。**

## 方法
- 探针目录：`data/probe_person_noscreen/`（gitignored）。预处理=部署口径（cv2 灰度→resize96 INTER_AREA→/255；int8 再量化）。
- 防泄漏：Pexels-ID(文件名) + 感知哈希(pHash≤阈 且 像素相关≥阈，复用 `check_leakage` 同口径) 双重核对，剔除与 train/val/test 撞图/近重复的探针。
- 两个守门员：`keras(float)` 与 `int8(.tflite)`（自含 int8 运行时，口径复刻 `hardware/infer.py` 部署预处理）。部署阈值 0.55，另列 0.5/0.7/0.9。

## 1. 防泄漏核对
- 探针总数 235；剔除泄漏 0 张（Pexels-ID 撞 0 / 感知近重复 0）；**干净探针 235 张**用于 FP 测。

## 2. 误触发率（FP）—— 干净探针，GT 全=不记

**keras(float)**

| 阈值 | 判「记」/总数 | FP 率 |
|---|---|---|
| 0.5 | 59/235 | **25.1%** |
| 0.55 | 53/235 | **22.6%**  ← 部署 |
| 0.7 | 26/235 | **11.1%** |
| 0.9 | 2/235 | **0.9%** |

**int8(.tflite)**

| 阈值 | 判「记」/总数 | FP 率 |
|---|---|---|
| 0.5 | 56/235 | **23.8%** |
| 0.55 | 51/235 | **21.7%**  ← 部署 |
| 0.7 | 26/235 | **11.1%** |
| 0.9 | 2/235 | **0.9%** |

## 4. 读数
- int8 部署阈值(0.55)下 FP **21.7%**：**中等**。有一定语境偏移，值得补多样化的实景人像负例；同时核对 FP 案例是否多为「半屏/反光」等边界图。
- keras 与 int8 的 FP 若明显不同，说明量化改变了工作点，部署阈值需按 int8 重标。
